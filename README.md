# AI Starter Library

Краткая библиотека для людей, которые впервые знакомятся с AI-чатами, AI-агентами, GitHub и базовыми компьютерными терминами.

## Что внутри

- `index.html` - готовая страница для GitHub Pages.

## Как обновлять

1. Изменить `index.html`.
2. Сделать commit.
3. Отправить изменения на GitHub.
4. GitHub Pages обновит сайт по той же ссылке.
